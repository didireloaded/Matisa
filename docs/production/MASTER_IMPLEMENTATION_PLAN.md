# MATISA MASTER IMPLEMENTATION PLAN

## Phases
- **Phase 0**: Repository and Database Stabilization (Package scripts, casing errors, baseline reports).
- **Phase 1**: Live Events Domain & Database Foundation (`events` feature domain, migrations, RLS, repositories, services, tests).
- **Phase 2**: Event Detail, RSVP & Discovery.
- **Phase 3 & 4**: Free Live Audio & Video Events (LiveKit token generation, rooms, roles, stage requests).
- **Phase 5 & 6**: Payment Foundation, Sandbox Tickets & Production Payment Provider.
- **Phase 7**: Recording, Replay & Settlement.
- **Phase 8**: Hardening, Observability & Release.
- **Subsequent Social Systems**: Liking (`reactions`), Sharing (`shares`), Comments (`comments`), Saves (`saves`), User Rating (`ratings`), Voice (`voice`), Karaoke (`karaoke`), Explore (`explore`), Notes (`notes`), and Anonymous Wall (`wall`).
